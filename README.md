# DrawingAIGame

An interactive AI-powered drawing recognition game built using **React** and **Firebase**.  
Players draw objects based on prompts, and the game provides instant feedback using a trained AI model.

## 🌐 Live Demo
👉 [Play the game](https://drawingai-f48d3.web.app)

## Overview
This project was developed during university as a personal exploration of **AI in web-based games**. It combines a responsive front end with real-time backend services for a smooth drawing experience.

## 🛠 Tech Stack
- **Frontend:** React, JavaScript, HTML5 Canvas, CSS3  
- **Backend / Hosting:** Firebase

## ✨ Features
- Real-time drawing interface  
- Instant AI recognition of drawings  
- Score feedback system  
- Hosted with Firebase
